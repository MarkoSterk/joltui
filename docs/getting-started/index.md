# Getting started

This section creates a new project, configures TypeScript and Vite, and builds a minimal
application with one layout and two pages. The concepts behind each file are explained in the
[guide](../guide/index.md); here the aim is to get something on the screen.

1. [Installation](installation.md): packages, TypeScript and Vite configuration.
2. [Quickstart](quickstart.md): a layout, two pages, a router and the application.
3. [Project layout](project-layout.md): where the files of a JoltUI application usually live.
4. [A first component](first-component.md): an interactive component with reactive state.

!!! tip "Already know Web Components?"

    A JoltUI component *is* a custom element. Everything you know about `HTMLElement`, the
    light DOM and global style sheets still applies. JoltUI uses no shadow DOM, so frameworks
    such as Bootstrap style components directly.
